# SimplePool

Languages
：[简体中文](readme/README-zh-CN.md)
| English

A simple memory pool that can be called by other languages.

## Build
Run:
```
mkdir build && cd build
cmake ..
make
```

And the header file (simple_pool.h) has been placed in /build/include.

## Document
Run:
'''
doxygen
'''

Document placed in build/docs/html now!
